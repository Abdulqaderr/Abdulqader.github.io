Data Quality & Reconciliation Framework

An automated control layer that compares operational sources with warehouse targets and makes data failures visible, measurable, and actionable.

PythonSQLCDCAutomation

Framework design uses synthetic examples and excludes employer data, schemas, and business rules.

Validation flow

Extract source→Resolve CDC latest state→Compare target→Classify variance→Report

Completeness

  • Source and target record counts
  • Missing business keys
  • Deleted-record handling

Uniqueness

  • Duplicate business keys
  • ROW_NUMBER deduplication
  • Unexpected fan-out checks

Accuracy

  • Attribute-level mismatches
  • Null and domain validation
  • Aggregated amount reconciliation

Freshness

  • CDC event lag
  • Latest-record logic
  • Pipeline watermark checks

Latest-record SQL

SELECT * EXCEPT(row_num) FROM ( SELECT *, ROW_NUMBER() OVER ( PARTITION BY business_id ORDER BY cdc_timestamp DESC, sequence_number DESC ) AS row_num FROM raw.cdc_events ) WHERE row_num = 1 AND operation != 'DELETE';

Automated output

Python orchestrates parameterized checks, writes exceptions to audit tables, produces summary metrics, and routes failures for investigation. Each result retains run time, rule, source, target, severity, and sample record keys.
